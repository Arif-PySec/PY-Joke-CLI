# 🎭 Real Jokes Generator (Python CLI)

An interactive, terminal-based Python tool that fetches live setups, puns, and punchlines from JokeAPI while keeping track of your session history and favorite jokes!

## ✨ Features
- 🌐 **Live Humor Feed:** Connects dynamically to JokeAPI over HTTPS.
- ⭐ **Favorites Tracking:** Save your top punchlines in memory during your session.
- 📜 **Session History:** Review all jokes generated during the run.
- 🛡️ **Zero External Dependencies:** Built purely using standard Python standard libraries (`json`, `urllib`).

## 🚀 How to Run
```bash
python WannaLaugh.py
